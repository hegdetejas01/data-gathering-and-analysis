# Population Versus Sample
    - Population: Entire group of objects that we need to study and draw conclusion
    - Sample: Random subset of population, to be the representative of larger population.

# Parameter Versus Estimate
    - Parameter: Numerical value that discribes the characters of the population like mean, var, std etc. It is generally unknown and are represented in Greek letters.
    - Estimate/Statistic: Numerical value that discribes the characters of the sample. It helps to make inferences of the unknown respective parameter of the population

# Inferential Statistics: 
    It helps to make predictions, estimations, generalisations about the larger population based on the sample of data taken from that population. It involves hypothesis testing, regression analysis, confidence interval.

### Point Estimate ###
    * It is a single value calculated from the sample that acts as a best guess for an unknown population parameter (eg. mean, std, variance etc). It helps to make inferences about the population.
    * Point estimates are unreliable.
    * Instead of a point estimate, it is better to predict a range - this is confidence interval
    

### Confidence Interval ###
    * Confidence Interval: It is a range of values within which we expect a particular population parameter (eg. Mean etc)
    * Confidence Level: It is expressed as a percentage like 95%, indicates how sure we are that the true value lies within the interval
    * Confidence Interval is calculated for Parameter with the help of estimate/statistic

    Formula:
        Confidence Interval = PointEstimate (+)(-) MarginOfError

    Ways to calculate Confidence Interval
        1. Z-Procedure: Helps when we have std of the population
        2. t-Procedure: Helps when we don't have std of the population


### Z-Procedure/ Sigma Known ###
    * Assumptions to apply z-Procedure
        1. Samples should be random
        2. Population std should be available
        3. Distribution of the population should be normal distribution except that if the distribution is not normal, CLT can be applied, and the sampling distribution (which will be normal distribution) can be used ( only when sample size > 30 )

    * Formula to calculate CI (confidenceInteval.pdf)

        PointEstimate (+)(-) Z(alpha/2) * std / sqrt(n)
        mu = x-bar (+)(-) Z(alpha/2) * std / sqrt(n)

            1-alpha is the confidence level (Eg: 95%)
            n = sample size
            std = standard deviation of the population
            PointEstimate = mean, std, variance etc

        For, confidenceLevel of 95% i.e 0.95
        PointEstimate (+)(-) Z(0.025) * std / sqrt(n)
        mu = x-bar (+)(-) Z(0.025) * std / sqrt(n)

    * mu = x-bar (+)(-) 1.96 * std / sqrt(n)
    This is the CI with a confidence level of 95 percent, i.e, z(alpha/2) = 1.96

    * mu = x-bar (+)(-) 1.13 * std / sqrt(n)
    This is the CI with a confidence level of 75 percent, i.e, z(alpha/2) = 1.13

    * Forming standard normal variate

        Z -> (xbar - mu)/(std/sqrt(n))

    * Interpreting Confidence Interval
        - Confidence level is not probability
        - if the CI of a age is [14-42] with confidence level of 95 percent means =
            then from sampling mean (taking random 50 datas for 100 times from the population), then 95 times the average age lie in that range

            A confidence interval is a range of values within which a population parameter, such as the population mean, is estimated to lie with a certain level of confidence. The confidence interval provides an indication of the precision and uncertainty associated with the estimate. To interpret the confidence interval values, consider the following points: 
            
            1 . Confidence level: 
                The confidence level (commonly set at 90%, 95%, or 99%) represents the probability that the confidence interval will contain the true population parameter if the sampling and estimation process were repeated multiple times. For example, a 95% confidence interval means that if you were to draw 100 different samples from the population and calculate the confidence interval for each, approximately 95 of those intervals would contain the true population parameter.

            2. Interval range: 
                The width of the confidence interval gives an indication of the precision of the estimate. A narrower confidence interval suggests a more precise estimate of the population parameter, while a wider interval indicates greater uncertainty. The width of the interval depends on the sample size, variability in the data, and the desired level of confidence.

            3. Interpretation: 
                To interpret the confidence interval values, you can say that you are "X% confident that the true population parameter lies within the range (lower limit, upper limit)." Keep in mind that this statement is about the interval, not the specific point estimate, and it refers to the confidence level you chose when constructing the interval.

    * Factors affecting margin of error

        MoE = (upper - lower) / 2

        1. Confidence Level (+ve relation)
        2. Sample size (+ve relation)
        3. Population std (-ve relation)





### t-Procedure / Sigma Not Known Procedure ###
    * This is more used than Z-Procedure because we usually don't have the knowledge of the std of the population
    
    * Assumptions:
        1. Random sampling
        2. Distribution of the population should be normal distribution except that if the distribution is not normal, CLT can be applied, and the sampling distribution (which will be normal distribution) can be used ( only when sample size > 30 )
        3. Sample std deviation
        4. All obersavtions are independent obersavtions

    * Formula

        CI = x-bar (+)(-) Z(alpha/2) * s / sqrt(n)
            s = sample standard deviation

            The below formula cant be used to calculate Z in t-Procedure because we don't know std of the population
            Z -> (xbar - mu)/(std/sqrt(n))

            Therfore we use,
                Z -> (xbar - mu)/(s/sqrt(n))
                - But, this doesn't give a normal distribution, instead it gives "STUDENT'S T DISTRIBUTION" - 
                    * Similar to normal distribution but not exactly normal distribution
                    * This is the theoratical distribution and donot occur in nature
                    * It depends on 'degree of freedom' = n-1, n is sample size
                    * The tail is fatter compared to the normal distribution
                    * If, degree of freedom = infinity, 
                    then normal distribution = student's t distribution

                * Because of these reasons we can't use Z 
                Therefore, the fomula becomes
                    --> CI = x-bar (+)(-) T(alpha/2) * s / sqrt(n)
    
    * Final Formula:
        CI = x-bar (+)(-) T(alpha/2) * s / sqrt(n)

        For the same confidence level and for lower level of degree of freedom, generally 
            --> Z(alpha/2) < T(alpha/2) , 
                    This also increases the confidence interval range
